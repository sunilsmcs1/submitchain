SubmitChain Explorer

Look up a manuscript submission by its ID, the way a blockchain explorer looks up a transaction.

Demonstration prototype. The ledger runs in this browser tab and resets on reload. Journals, authors and manuscripts are invented examples. Fingerprints here use word-level SimHash; the full system uses semantic embeddings on Hyperledger Fabric.

    This is what a journal's editorial system does when a manuscript arrives. The title and abstract stay with the journal. Only the ID, the author pseudonym, the fingerprint and the status go on the ledger.

    The pre-filled text rewords an example already under review at another journal, so it should raise an alert.
